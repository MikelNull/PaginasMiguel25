Ciberseguridad

Tipos de Malware

Tipo de Malware Función Impacto
Virus Autoreplicable, infecta archivos Daño de datos y sistemas
Gusanos Se propaga por las redes Interrupción de la red, agotamiento de recursos
Caballo de Troya Se disfraza de software legítimo Robo de datos, control de sistemas
Ransomware Cifra archivos y exige pago Extorsión, pérdida de acceso a datos
Software espía (Spyware) Supervisa en secreto la actividad del usuario Violación de privacidad, robo de datos
Software publicitario (Adware) Muestra anuncios no deseados Reducción de rendimiento, violación de privacidad
Rootkit Oculta software malicioso Acceso no autorizado, amenazas persistentes
Keylogger Registra pulsaciones de teclas Robo de credenciales, filtración de datos
Fileless Malware (Sin archivos) Opera en memoria, sin archivos en disco Ataques sigilosos y difíciles de detectar
Cryptojacker Minería de criptomonedas sin consentimiento Problemas de rendimiento, consumo excesivo de recursos
Botnet (Red de bots) Red de dispositivos infectados controlados remotamente Ataques DDoS, distribución de spam
Bomba Lógica Ejecuta código malicioso al cumplirse una condición Destrucción de datos, daños al sistema
Wiper (Destructor de datos) Destruye o borra datos de forma intencionada Pérdida irreversible de información
