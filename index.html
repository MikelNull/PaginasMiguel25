Gestor Académico Inteligente

Guía para principiantes: Tu primera app móvil

Bienvenido/a. No necesitas saber programar. Te guiaré paso a paso para crear tu primera app móvil con Flutter y Firebase. Cada paso explica el porqué, qué verás en pantalla y los errores comunes.

Frase clave del proyecto: "Una app educativa exitosa no es la más bonita – es la que protege a los alumnos mientras reduce el trabajo del maestro en un 70%."

1) ¿Qué vamos a construir?

Una app llamada Gestor Académico Inteligente con tres roles y funciones clave como pase de lista con QR, evaluaciones con IA y reportes automáticos. Todo pensado para docentes con poco tiempo.

ADMIN MAESTRO ESTUDIANTE

2) Instalación desde cero (sin experiencia)

Paso 1. Instalar Flutter

Flutter es la herramienta para crear apps Android e iOS con un solo código.

1) Entra a https://flutter.dev/docs/get-started/install 2) Descarga Flutter para tu sistema 3) Extrae la carpeta en C:\\src\\flutter (Windows) o ~/development/flutter (Mac/Linux)

Captura esperada: Verás una carpeta llamada flutter con subcarpetas como bin.

Paso 2. Instalar Android Studio

Android Studio incluye el emulador para probar tu app sin un teléfono real.

1) Entra a https://developer.android.com/studio 2) Descarga e instala Android Studio 3) Abre Android Studio y completa el asistente inicial

Captura esperada: Verás la pantalla de bienvenida con el botón “New Project”.

Paso 3. Configurar el SDK de Android

El SDK son las herramientas para compilar apps Android.

1) En Android Studio, abre Settings 2) Ve a “Android SDK” y marca Android 14 o 13 3) Presiona “Apply”

Errores comunes: “SDK not found”. Solución: instalar SDK desde Android Studio.

Paso 4. Verificar Flutter

Abre la terminal (cmd o PowerShell en Windows) y ejecuta:

flutter doctor

Captura esperada: Verás checks verdes. Si aparece un error rojo, sigue la sugerencia que muestra Flutter.

3) Crear tu primer proyecto Flutter

Paso 1. Crear el proyecto

flutter create gestor_academico cd gestor_academico

Captura esperada: Carpeta con archivos como lib y pubspec.yaml.

Paso 2. Ejecutar por primera vez

flutter run

Captura esperada: El emulador muestra una app con un contador.

Errores comunes: “No devices found”. Solución: abrir un emulador en Android Studio.

4) Conectar Firebase (gratis)

Paso 1. Crear proyecto en Firebase

1) Entra a https://console.firebase.google.com 2) Crea un proyecto llamado gestor_academico 3) Activa Authentication, Firestore y Storage

Captura esperada: Panel con tarjetas de Auth, Firestore y Storage.

Paso 2. Conectar la app

En Firebase, registra tu app Android y descarga el archivo google-services.json.

Captura esperada: Archivo descargado en tu carpeta de descargas.

Importante: Nunca subas claves privadas a repositorios públicos. Mantén tu app segura desde el día 1.

5) Roles y pantallas principales

Así se verá tu estructura funcional:

  • Admin: Control total, 2FA obligatorio, dashboard global.
  • Maestro: Máximo 3 grupos, QR y código numérico para asistencia.
  • Estudiante: Perfil académico, ver tareas y marcar asistencia.

6) Funciones clave (explicadas fácil)

Pase de lista ultrarrápido

El maestro genera un QR válido por 5 minutos. El alumno lo escanea y queda presente.

Objetivo de tiempo: 100 alumnos en menos de 60 segundos.

Evaluaciones con IA

La IA sugiere calificaciones según una rúbrica, pero el maestro decide la calificación final.

Beneficio: Reduce el tiempo de evaluación hasta 70%.

7) Checklist para avanzar sin errores

  • Instalé Flutter y Android Studio.
  • Ejecuté flutter doctor y todo quedó en verde.
  • Creé el proyecto y lo corrí en un emulador.
  • Activé Firebase Auth, Firestore y Storage.
  • Entiendo que la seguridad es prioridad (datos de menores).

8) Errores comunes y soluciones

Error: “No devices found”

Abre Android Studio > Device Manager > Create device y ejecuta el emulador.

Error: “SDK not found”

Instala el SDK desde Android Studio > Settings > Android SDK.

Error: “Gradle build failed”

Revisa tu conexión a internet y vuelve a abrir el proyecto.
