Gestor Académico Inteligente

Guía paso a paso para principiantes (0 experiencia)

Objetivo: ayudarte a crear tu primera app móvil que reduzca 70% del trabajo administrativo del docente. Aquí no asumimos conocimiento técnico y te guiamos desde la instalación hasta la primera ejecución.

Principio clave: “El código sin análisis previo es un error costoso”. En cada paso explico por qué es importante y qué valor aporta al negocio.

1) Qué vamos a construir (visión simple)

Construiremos un Gestor Académico Inteligente con tres niveles de acceso:

  • ADMIN Control total y 2FA obligatorio.
  • MAESTRO Gestiona hasta 3 grupos y pase de lista.
  • ESTUDIANTE Ve su perfil y marca asistencia.

Valor de negocio: ahorra tiempo, evita errores y protege datos de menores.

2) Preparación del entorno (instalar herramientas)

Necesitas instalar estas herramientas. Copia exactamente los comandos. Usaremos Flutter para crear apps para Android y iOS.

  1. Instala Flutter
    Captura sugerida: página oficial de Flutter con botón “Get started”.

    Ve a https://flutter.dev y descarga la versión estable.

  2. Instala Android Studio
    Captura sugerida: pantalla inicial de Android Studio con “New Flutter Project”.

    Incluye el SDK de Android. Es imprescindible para ejecutar la app.

  3. Configura variables y verifica instalación

    Abre la terminal y ejecuta:

    flutter doctor

    Verás una lista con marcas verdes. Si aparece una X roja, revisa el mensaje y sigue la indicación. Esto evita errores futuros.

3) Crear tu primer proyecto Flutter

Este paso crea la base del proyecto. Lo hacemos antes de Firebase porque Firebase necesita un proyecto Flutter existente. 

flutter create gestor_academico
cd gestor_academico
Captura sugerida: terminal mostrando “Project created successfully”.

Ahora abre el proyecto en Android Studio y confirma que ves las carpetas: lib/, android/, ios/.

4) Conectar Firebase (autenticación y base de datos)

Firebase guardará usuarios, grupos, asistencias y reportes. Esto es crítico porque necesitamos privacidad y reglas de acceso estrictas.

  1. Crea un proyecto en Firebase Console: https://console.firebase.google.com.
  2. Agrega apps Android e iOS usando el mismo nombre del paquete Flutter.
  3. Descarga los archivos de configuración y colócalos en el proyecto.
Captura sugerida: Firebase Console con el botón “Add app”.

Errores comunes: usar un nombre de paquete diferente provoca fallos al iniciar sesión.

5) Estructura de roles y seguridad (visión simple)

La seguridad protege a menores y evita que un alumno vea datos de otro. Aquí está la regla mental simple:

  • Admin ve todo.
  • Maestro ve solo sus grupos.
  • Estudiante ve solo su perfil.
Campos críticos encriptados: nombre, matrícula, calificaciones y asistencia. Esto mantiene privacidad total si alguien accede a la base de datos.

6) Primer prototipo visual (pantallas clave)

Vamos a diseñar el prototipo antes de programar. Esto evita retrabajo y ayuda a visualizar el flujo del usuario.

Captura sugerida: boceto simple con 3 pantallas: Login, Dashboard Maestro, Perfil Alumno.
  • Login con selección de rol.
  • Dashboard Maestro con botón “Generar QR”.
  • Perfil Alumno con asistencia mensual.

7) Primer ejecución en emulador (tu gran momento)

Este paso confirma que el entorno funciona. Es la primera victoria y evita frustraciones posteriores.

  1. Abre Android Studio y crea un emulador (AVD).
  2. En terminal, ejecuta:
flutter run
Captura sugerida: emulador abierto mostrando la app de Flutter en pantalla.

8) Checklist mínimo antes de seguir

  • Flutter doctor con todo en verde.
  • Proyecto creado y abierto en Android Studio.
  • Firebase conectado sin errores.
  • Emulador ejecutando la app.

Si algo falla, revisa los pasos anteriores y valida el error en consola. La mayoría de problemas se deben a rutas o SDKs incompletos.

9) Próximas fases (ruta de aprendizaje)

  1. Autenticación por rol (Admin, Maestro, Estudiante).
  2. Dashboard Maestro con asistencia QR + código.
  3. Evaluaciones con rúbricas + sugerencias IA.
  4. Reportes automáticos y alertas inteligentes.

Cada fase agrega valor real al docente. El objetivo es lograr acciones críticas en menos de 3 segundos.

Frase clave: “Una app educativa exitosa no es la más bonita – es la que protege a los alumnos mientras reduce el trabajo del maestro en un 70%.”
